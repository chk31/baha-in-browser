# ここまでの経緯（2026-11-23 時点）

## 目標
- このゲームに慣れた人間に勝ち越せるCPUを作る。
- ブラウザで遊べる対戦アプリを作る（スマホ中心）。
- AIの開発を通じて、ゲームの攻略（勝ち筋）を調べる。

## CPU の系譜
| CPU | 中身 | アプリ |
|---|---|---|
| ふつう | 基本の戦略ルール | 公開 |
| つよい | 相手の手札を確率で読み、書の枚数を計算して打つルールCPU | 公開 |
| AI2 | 強化学習（MaskablePPO）。自己対戦中心で450万ステップ | 非公開（分析用） |
| AI3 | AI2から、打ち方の違う相手とも戦って750万ステップ | 非公開 |
| AI4 | 相手の打ち方の履歴も入力に足して800万ステップ | 非公開 |
| AI5 | 詰み回避・勝ち切りの盤面を重点的に練習 | 公開 |
| AI6 | AI5から1,000万ステップ超。勝ち切り・詰み回避・穴の盤面を先生役で教えた | 公開 |
| **AI6.5** | AI5から3,000万ステップまで同じ方法で続けた | 公開（初期値） |

- 方策の入力は公開情報234次元（基本179＋相手の行動履歴55）、出力は19通りの行動（マスクつき）。隠れ層256×2、tanh。
- アプリでは、強化学習CPUを確定手ルールで包んで使う（「ルールつき」）。

## 確定手ルール（`app/rules.js`）
| ルール | 内容 |
|---|---|
| R1 | このターンに勝ちが確定する手順があれば、それを打つ |
| R2 | 次の相手の攻撃で負ける形なら、それを避ける手順を打つ |
| R5 | 自分の場にゴブリンがいれば、相手のナイフは打ち消さない（跳ね返す） |
| R6 | 通すと負けるカードは打ち消す |
| R7 | 手札を捨てるとき、R1・R2 の手順に使うカードを残す |
| R8 | 効果が確実に何も起きないカードには書を使わない |

R3（対処の道を残す）は確実でないので外した。経験則のルールは入れない方針。

## 強さ（確定手ルールつき同士、同じ配牌で席を入れ替えた2,000局ずつ、誤差±0.011）
行のCPUが列のCPUに勝つ率。

|---|---|---|---|---|---|---|---|
| AI6.5 | – | 0.550 | 0.612 | 0.674 | 0.727 | 0.785 | 0.902 |
| AI6 | 0.450 | – | 0.570 | 0.617 | 0.701 | 0.744 | 0.892 |

新しいモデルは古いすべてに勝ち越していて、すくみ（非推移）は無い。

## ゲームについて分かっていること（AI6同士の大量対戦から）
- 後攻が約60%勝つ。
- 勝敗に一番効くのは書の量。通した魔女の差が±2枚で勝率が約24ポイント動く。
- ナイフは2本通せば必ず勝ち（2点×2）、1本だけでは勝率はほぼ変わらない。
- 打ち消されやすいのはイデヨン（66%）・イレカエール（58%）・ヨミガエール（56%）。
- 初手で良いのは魔女・ゴブリン（約+6ポイント）、悪いのは砂時計（約−9ポイント）。
- 中盤のライフ差は当てにならない（ゴブリンの跳ね返し、はらぺこの4点で一気に逆転する）。

## 分かっている弱点
- 書の最後の1枚の使い道（公開されたイデヨンがあるのに別のカードを止める、など）。打ち消しの判断は、今の学習の先生役に入っていない。
- 人間との対戦記録は約35局（claude.ai のアーティファクトの DB にある）。
