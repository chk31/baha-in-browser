# オンライン対戦（合言葉）の使い方と設定

設計の考え方は `ONLINE_PLAN.md`。ここは実装の要点と、Firebase に切り替える手順。

## 遊び方
1. 片方がタイトル画面の「部屋を作る」を押す → 合言葉（英数字5文字。I・L・O・0・1 は使わない）が出る。
2. もう片方が「部屋に入る」で合言葉を入れる → 対戦開始（先攻・後攻はランダム）。
3. 決着したら、部屋を作った人が「もう一度（同じ相手と）」で続けて遊べる。「退出」でタイトルへ。

## 通信方式
| 設定 | 使われる方式 |
|---|---|
| `app/online_config.js` の `FIREBASE_CONFIG` が `null`（今の状態） | **PeerJS（WebRTC）**。設定不要。公開の仲介サーバー `0.peerjs.com` を使う。スマホのモバイル回線同士だとつながらないことがある |
| `FIREBASE_CONFIG` に値を入れる | **Firebase Realtime Database**。どの回線でもつながりやすい |

URL に `?net=peer` を付けると、Firebase の設定があっても PeerJS を使う（`?net=local` は同じブラウザの別タブ同士でつなぐ試験用）。
両方の端末が同じ版のページを開いている必要がある（版が違うと入室時に知らせる）。

## Firebase に切り替える手順
1. https://console.firebase.google.com/ で「プロジェクトを追加」（Google アナリティクスはオフでよい）。
2. 左のメニュー「構築 → Realtime Database」→「データベースを作成」。場所は近い所（例：シンガポール asia-southeast1）、「ロックモードで開始」。
3. 「ルール」タブに次を貼って「公開」：
   ```json
   {
     "rules": {
       "rooms": {
         "$code": {
           ".read": "$code.length === 5",
           ".write": "$code.length === 5"
         }
       }
     }
   }
   ```
   （部屋の一覧は読めない。合言葉を知っている人だけがその部屋を読み書きできる。友人同士で遊ぶ前提の設定。）
4. 「プロジェクトの設定（歯車）→ 全般 → マイアプリ」でウェブアプリ（`</>`）を追加し、表示された `firebaseConfig` の値を `app/online_config.js` の `FIREBASE_CONFIG` に書く。`databaseURL` が入っていることを確認する（無ければ Realtime Database の画面上部の URL）。
5. `main` に push すれば GitHub Pages に反映される。

この `apiKey` などはページに埋め込まれて誰でも見られるが、Firebase のウェブ用設定は公開して使う前提のもの。守りは上のルールで行う。

部屋のデータは `rooms/<合言葉>` に入る。部屋を作った人が退出すると消える。残ったものも、6時間たてば同じ合言葉で作り直せる（気になったらコンソールから `rooms` ごと消してよい）。

## 仕組み（`app/online.js`）
- **ホストが進行役。** ホストのブラウザが `runGame(s,[human, remoteAgent(s)])` を動かす。エンジンの中ではホスト=0、ゲスト=1。エンジン・確定手ルール・CPU には手を入れていない。
- **ゲストはエンジンを動かさない。** ホストから届く `view`（ゲストから見える状態）を、自分が `players[0]` になる向きに並べ直し、CPU対戦と同じ画面・同じ `human` で答える。
- 送るもの：`start` / `view`（画面更新のたび）/ `ask`（判断の依頼。そのときの状態つき）/ `answer` / `end` / `ping` / `bye` / `hello`（版の確認つき）。
- **隠れた情報は送らない。** `view` のホストの手札は枚数だけ、山札も枚数だけ。構造化ログ `s.ev` は送らない。吹き矢・メガネの中身は、使った本人への `ask` にだけ入る。文章ログ `s.log` は元々、引いたカード名を出さない。
- ログの名前は目印（``=ホスト、``=ゲスト）で持ち、見る人に合わせて「あなた」「相手」に置き換える。
- ゲストの答えは、ホスト側で確かめてから使う（手札に無いカードなどは無効）。
- 4秒ごとに `ping`。12秒返事が無ければ「通信が不安定」と出し、45秒で中断。ページを閉じたときは `bye` を送る。
- オンライン対戦では「AIのおすすめ」は使わない。対戦記録も保存しない。
- 途中で切れた対戦の再開はできない。
