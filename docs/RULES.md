# はらぺこバハムート ルール

## 準備
- 2人対戦。16種類のカードが1枚ずつ。各自ライフ4、手札5枚、うちけしの書2枚。書のストック2枚（書は合計6枚）。残り6枚が山札。

## 手番の流れ
1. 手番の始めに、自分の場のこども → はらぺこの順で攻撃する（こども1点、はらぺこ4点）。
2. 1枚引く。
3. 最大2枚プレイする。
4. 手札が5枚を超えていれば、5枚まで捨てる。
- 先攻の1ターン目は引かず、プレイは1枚まで。
- 山札が切れたら、捨て札を混ぜて山札にする。
- ライフが0になったら負け。

## うちけしの書
- 相手がカードをプレイしたとき、書1枚で打ち消せる。打ち消されたカードは捨て札へ。
- 打ち消されたら、書2枚で「うちけし返し」ができる。うちけし返しは打ち消せない。

## カード（16枚）
| カード | 効果 |
|---|---|
| はらぺこバハムート | 手札から直接は出せない。イデヨン・ヨミガエール・イレカエールで場に出る。持ち主の手番の始めに相手へ4点 |
| こどもバハムート | 場に出す。持ち主の手番の始めに相手へ1点 |
| はねかえしゴブリン | 場に出す。はらぺこ以外のダメージを相手に跳ね返す（跳ね返りは1回） |
| イデヨン！ | 手札のまものを1体場に出す |
| ヨミガエール！ | 捨て札のまものを1体場に出す |
| イレカエール！ | はらぺことこどもの位置を、すべての場所（手札・場・山札・捨て札）で入れ替える |
| オワカーレ！ | 場のカード1枚を捨て札にする |
| そらとぶナイフ | 相手に2点 |
| 魔女のおとどけもの | ストックから書を1枚得る |
| ほしふる砂時計 | この手番に追加で2枚プレイできる |
| カラスのおつかい | 捨て札から1枚を手札に加える |
| 銀ネコのしっぽ | 3枚引き、2枚捨てる |
| 黒ネコのしっぽ | 2枚引き、2枚捨てる。追加で1枚プレイできる |
| ひらめき水晶 | カード名を宣言し、相手の手札にあれば奪う |
| ようせいのメガネ | 山札の中身を見て1枚選び、手札に加える |
| あくまの吹き矢 | 相手の手札を見て1枚選び、捨てさせる |

## 確認済みの裁定
- ゴブリンはこども自身の攻撃も跳ね返す（自分のこどもが相手のゴブリンに跳ね返されると、自分が受ける）。
- 砂時計・黒ネコもプレイ回数に数える。
- 対象は解決時に選ぶ。
- ようせいのメガネは、山札が0枚なら何も起きない（捨て札を切り直さない）。
